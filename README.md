# Última guardia (Intento de Titulo)

Última guardia es un intento de FPS en primera persona hecho con HTML, JavaScript y Three.js. El objetivo es  atravesar las salas, pasillos y escaleras de un hospital abandonado y alcanzar la zona de extracción para terminar del recorrido.

* Cómo ejecutarlo

1. Abre esta carpeta en Visual Studio Code.
2. Usa la extensión Live Server para abrir `index.html` con la opción **Open with Live Server**.
3. Pulsa **Iniciar misión** cuando aparezca y a jugar.

* Controles
W, A, S, D : Caminar
Mover el Mouse : Mirar
Clic izquierdo : Disparar una vez
Teclas 1 y Tecla 2 : Cambiar de arma
Esc : Pausa

* Reglas

- Comienzas con 12 balas en la M4A1 y 8 en la AK-47. Cada arma conserva su munición al cambiarla.
- Si el zombi te toca, pierdes.
- Hay cajas de munición en el mapa que se puede recoger. Cada una entrega 6 balas para la M4A1 y 4 para la AK-47.
- Puedes reiniciar tras ganar o perder. Se restaura los elementos del mapa.
